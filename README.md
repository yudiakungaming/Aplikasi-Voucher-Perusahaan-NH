# FinanceSync Pro Monorepo

Repositori terintegrasi untuk sistem pencatatan keuangan dan dashboard monitoring.

## 📂 Struktur Aplikasi

### 1. 📝 Input Voucher (`/apps/input-voucher/`)
Aplikasi untuk pencatatan transaksi, pengajuan voucher, dan integrasi Google Drive.
- **Path:** `apps/input-voucher/`

### 2. 📊 Dashboard Voucher (`/apps/dashboard-voucher/`)
Aplikasi untuk melihat rekapitulasi data, grafik statistik, dan export laporan.
- **Path:** `apps/dashboard-voucher/`

##  Cara Menggunakan
1. Buka root repository (halaman utama).
2. Pilih aplikasi yang ingin digunakan (Input atau Dashboard).

## 🔧 Developer Notes
- Repository ini menggunakan struktur monorepo sederhana.
- Kedua aplikasi berjalan secara independen namun terhubung via navigasi.
