🎨 FinanceSync Icon Generator

Generator ini akan membuat 4 icon PWA yang dibutuhkan (192x192, 512x512, + versi maskable). Klik tombol di bawah, lalu download file yang muncul.

Langkah Selanjutnya:
1. Buat folder /icons/ di root proyek Anda
2. Pindahkan 4 file PNG yang sudah didownload ke folder tersebut
3. Pastikan nama file persis seperti ini:
icon-192x192.png, icon-512x512.png, icon-192x192-maskable.png, icon-512x512-maskable.png
4. Refresh halaman & test install PWA di Chrome!
